# ST-PresetAssistant 预设助手

**ST-PresetAssistant**（在 SillyTavern 预设列表中显示为 **`ST-预设助手`**，当前版本 **`v0.6.0`**）是一套适用于 SillyTavern 对话补全模式的互动小说预设，内置多 AI 人设切换、模块化写作与规则开关、四页签悬浮控制面板以及对话卡片美化。

---

## 环境要求

- **SillyTavern（酒馆）**：使用 Chat Completion（对话补全）模式连接模型接口。
- **酒馆助手 (`JS-Slash-Runner`)**（推荐启用）：用于运行悬浮控制面板、主题配色记忆、批注写回与选项快捷填入功能。未安装该扩展时，预设写作规则与基础折叠正则仍可正常使用，但悬浮面板与卡片交互按钮不可用。
- **内置正则保持开启**：导入预设时会附带内置正则，请保持它们处于启用状态。

---

## 安装与升级

1. **下载预设**：在仓库根目录下载最新的 [`ST-PresetAssistant_V0.6.0.json`](ST-PresetAssistant_V0.6.0.json)（历史正式版本归档于 [`history/`](history/)；若在 `dev` 分支查看，产物位于 [`presets/`](presets/)）。
2. **导入启用**：打开 SillyTavern 顶部 **AI 响应配置（预设）** 面板导入 JSON 文件，并在下拉列表中选择 **`ST-预设助手`**。
3. **版本升级**：预设在酒馆内的名称固定为 **`ST-预设助手`**。后续升级直接导入新版 JSON 并覆盖原预设即可，不会产生重复条目。

## 主要功能

### 1. 多 AI 人设与纯净接管
- 内置三位 AI 人设：**`莉莉丝`**（默认开启，魅魔写手，擅长情绪拉扯与成人向互动）、**`泠音`**（温和沉静，讲究留白与人物可信度）、**`Ark`**（冷静理性，注重世界自洽与细节观察）。
- 在悬浮面板点击当前激活的人设即可将其关闭，完全交由角色卡自身设定演绎。

### 2. 四页签悬浮控制面板（需搭配酒馆助手）
点击界面上的半透明 **`✨`** 悬浮球即可展开控制面板（可自由拖拽至屏幕任意位置，右上角点击 **保存** 可将修改永久写入预设存档）：
- **预设设置**：集中开关 `AI人设`、`核心规则`、`写作规范`（默认 / 宽松）、`文风`（情色文学、直白肉文、写实白描、细腻工笔、轻小说体、轻快网感、古风雅韵、典雅书面共 8 款）、`视角`、`节奏`、`侧重`、`NSFW倾向/细化`、`代写边界`、`篇幅`、`功能`（正文批注、行动选项、格式兼容、防复读检查、状态栏）、`总结`（场景小结 / 全局梳理，单选互斥）与 `思考`（输出思考面板、构思推演、多角色调度、预填充思考）。
- **参数设置**：内置 `Gemini4-low`、`Gemini4-high`、`Claude`、`DeepSeek` 四套参数方案，支持一键清零惩罚项、恢复默认参数，以及微调思考深度、回复上限、上下文长度和各类采样参数（不改动任何提示词开关与你的上下文上限）。
- **正则设置**：开关「美化设置」与「其他设置」，并内置「禁词清洗」词表（发送请求前从 AI 历史回复中剔除指定高频套话，不修改聊天记录与界面显示）。
- **助手设置**：按当前激活人设独立保存主题配色、查看或重置悬浮球位置，以及检查新版本更新。

### 3. 对话美化与上下文整理（9 条内置正则）
- **卡片美化**：自动将 AI 输出的思考过程、场景状态栏（时间｜地点｜在场人物）、正文 `※` 批注（支持直接编辑、删除与追加署名写回）、场景小结、全局梳理档案以及文末行动选项（支持一键填入或发送）渲染为独立界面卡片，并对正文中文对白与分割线进行润色。
- **历史整理**：发送对话给模型前自动剔除历史消息中的思考过程与行动选项，保留状态栏、正文批注与总结内容作为长对话记忆参考。

## 常见问题

- **看不到 `✨` 悬浮球**：请确认已安装并启用 **酒馆助手 (`JS-Slash-Runner`)**，且当前选中的预设为 **`ST-预设助手`**。
- **改了开关刷新后失效**：面板中的修改仅即时生效于当前会话；调整满意后请点击面板右上角 **保存** 写入预设存档。
- **对话只显示原始标签未渲染卡片**：请到悬浮面板 **正则设置** 或 SillyTavern 正则面板确认预设附带的 7 条 `[美化]` 正则均已开启。
- **Gemini 4 / Claude 报 `HTTP 400` 或输出截断**：
  - 若手动开启了 `[思考] 预填充思考` 并报 `400`，将其关闭即可；
  - 部分端点不支持惩罚参数时，可在 **参数设置** 点击 **清零惩罚项**；若 Claude 报 `temperature` 与 `top_p` 互斥，请在酒馆 API 连接的「排除请求体参数」中填入 `top_p`；
  - 内置思考会占用回复额度，建议将最大回复长度保持在 `16384`–`32768`。
