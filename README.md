# ST-PresetAssistant (`Starlight` · 星光预设)

**`ST-PresetAssistant`**（英文全称 **`Starlight-PresetAssistant`**，中文常称 **星光预设**；`ST` 同时代表 SillyTavern 与 Starlight，当前版本 **`v1.1.0`**）是一套适用于 SillyTavern 对话补全模式的互动小说预设。支持零人设纯净承接与多搭档人设切换、模块化写作与交互开关、附加趣味设定、四页签悬浮控制面板以及对话卡片美化。

---

## 一、快速上手

### 1. 准备条件
- **SillyTavern（酒馆）**：使用 Chat Completion（对话补全）模式连接你的模型接口。
- **酒馆助手 (`JS-Slash-Runner`)**（推荐启用）：用于运行悬浮控制面板、主题配色记忆、批注编辑与选项快捷填入。未安装该扩展时，预设本身的写作效果与基础美化正则仍可正常使用，仅悬浮窗与卡片快捷交互按钮不可用。
- **内置正则保持开启**：预设自带 12 条正则（卡片美化与历史整理），导入后保持启用即可。

### 2. 下载、导入与升级
1. **下载预设**：下载本仓库根目录的 [`ST-PresetAssistant_V1.1.0.json`](ST-PresetAssistant_V1.1.0.json)（过往版本存档在 [`history/`](history/) 目录）。
2. **导入启用**：打开酒馆顶部的 **AI 响应配置（预设）** 面板导入 JSON 文件，并在下拉列表中选择 **`ST-PresetAssistant`**。
3. **版本升级**：预设在酒馆内的名称固定为 **`ST-PresetAssistant`**，日后升级直接导入新版覆盖同名预设即可，不会多出重复条目。

### 3. 开箱默认体验
导入后无需折腾配置即可开玩。点击界面半透明 **`✨`** 悬浮球随时调整开关（悬浮球可自由拖到屏幕任意位置，调好后点面板右上角 **保存** 写入预设存档）：

- **开箱默认配置**：默认不开启 AI 人设（由中立温和的默认助手直接承接，尽量忠实角色卡本身风味），搭配 `第三人称限知`、`经典日轻`、`中性双向`、`张弛自然`、`自然均衡`、`适中 (800-1200字)`、`标准`写作规范、`直接承接`、`有限延伸`、`叙事推理-重度`、`输出思考面板`、`剧情选项`、`外部格式兼容` 与 `[核心任务] 续写故事`（`附加设定`、`思考增强`、`正文批注` 与 `预填充思考` 默认关闭）。
- **默认模型参数**：适配长上下文并默认对齐 `Gemini4-high` 常用参数（思考深度 `high`、最大回复长度 `32768`、最大上下文 `2000000`、`temperature: 1.0`、`top_p: 1.0`、各项惩罚为 `0`）。

## 二、面板功能与使用指南

打开 **`✨`** 悬浮球后共有四个页签，以下按玩家常见需求说明各功能的作用（每个分组旁的 **`?`** 图标也可随时点开查看说明）：

### 1. 预设设置：怎么选人设、文风与开关
面板中所有单选按钮再次点击即可关闭；带条件联动的小开关会在前置选项关闭时自动隐藏。

- **AI 人设（默认全关）**：
  - 默认不启用，开箱使用干净中立的默认助手；开启人设后会影响搭档的伴行语气、内容生成倾向，并有助于提升特定题材的表现力与放开程度（全部设在最前端，故事正文仍会贴合角色卡自身口吻与背景）：
    - **`泠音：剧情小说`**：温厚实在、注重日常烟火气与寻常人情（风格贴近老舍/冰心式生活质感）；
    - **`莉莉丝：肉文写手`**：坦率热辣、爱写肉文和爽文，擅长拉高暧昧张力与感官满足；
    - **`Ark：角色扮演`**：冷静克制、偏重规则推算与状态结算，适合跑团与严谨向剧情；
    - **`大肥鱼：努力干饭`**：把每次对话与 Token 当作香喷喷白米饭的蓝鲸看板娘，不挑题材、自由发挥、尽力把戏写得鲜活饱满。
  - 若你自己新建人设条目，只要开头说明自己是「玩家（user）的 Assistant」即可直接用，无需额外设置变量。
- **写作风格与视角细节**：
  - **视角**：默认 `第三人称限知`（紧贴主角所见所闻）；支持 `第一人称`、`第二人称` 与可切换多地多角色视角的 `第三人称全知`。
  - **文风（9 款）**：默认 `经典日轻`。包含 `经典日轻`、`新式轻文学`、`细腻工笔`、`情色文学`、`直白肉文`、`爽利网文`、`写实白描`、`古风雅韵` 与 `严肃正剧`，日常场景与成人戏份各自按你所选文风自然展现。
  - **NSFW 倾向 & 细化**：默认 `中性双向`（兼容任意角色性别组合），另有专注视觉力道反差的 `男性向` 与注重被珍视氛围感的 `女性向`；写全年龄纯日常时再点一次当前选项即可全部关闭。可按需加开 `反应多样性` 丰富不同角色的性事差异。
  - **节奏、侧重、篇幅与写作规范**：`节奏` 与 `侧重` 调整详略重心；`篇幅` 只做信息充沛时的展开参考，遇到简单对话会自然短收、不硬凑字数；`写作规范`（默认 `标准`）可减少高频 AI 套话与重复动作，想放宽句式时可切至 `宽松`。
- **附加设定（默认全关，多选）**：
  - 想要轻松整活或特定题材风味时可按需点亮，不影响默认游玩体验：
    - **`角色自我攻略`**：面对玩家礼貌或冷淡回应时，角色容易在心里脑补出心动理由；
    - **`全员迪化脑补`**：周围角色把主角的一言一行都当成深不可测的高人布局；
    - **`修罗场暗涌`**：多角色同场时暗自吃醋、试探与较劲；
    - **`戏剧性巧合`**：在平淡或僵持时适度触发贴合场景的意外契机；
    - **`沙雕喜剧`**：人物一本正经地闹乌龙、制造错位反差笑点。
- **输入处理与代写边界**：
  - **输入处理**：`直接承接`（默认）会把你已经写出来的动作和台词当作已经落地画面直接接写；`演绎展开` 会把你输入的简短提纲先扩写成生动段落再接续后续。
  - **代写边界**：`禁止代写` 完全不写主角未表达的言行与心情；`有限延伸`（默认）仅补足顺手过场动作与合理体感，把重要决定、表态与心理倾向留给你；`自由代写` 允许 AI 在共写模式下主动接管主角形成双向长互动。
- **思考、格式要求、核心任务与其他**：
  - **主思考 & 思考增强**：默认开启 `叙事推理-重度`（如果用自带原生思考的大模型觉得等待偏长，可切至 `轻量`）；`思考增强` 的五项开关按需选开 `1~2` 项即可（`多角色调度 / 心理潜台词 / 伏笔与暗线 / 防谄媚读心 / 防复读套话`）。
  - **格式要求**：
    - `输出思考面板`（默认开）：在正文前折叠显示 AI 的思考推演，便于排查跑偏；
    - `场景状态栏`（默认关）：正文开头附带一行 `时间｜地点｜在场人物` 状态条；
    - `正文批注`（默认关）：开启后 AI 会在落笔前衔接之前留存的未回收伏笔与有效状态，并在剧情转折反差、潜台词交锋、伏笔点或重要约定与物品伤势变更处，另起空行插 1 条 `※ 标签：内容`（支持点评、吐槽、伏笔、笔记及自定义标签，卡片内也可随时编辑或删除）；
    - `场景小结`（默认关）：文末生成简短剧情摘要，帮长对话稳住前情记忆；
    - `剧情选项`（默认开）：文末给出 `2~4` 个不同方向的后续选项，点一下即可填入输入框或直接发送；
    - `外部格式兼容`（默认开）：兼容角色卡自带的属性面板或状态标签，各自成块不打架。
  - **核心任务**：平时保持 `续写故事`；长对话需要梳理前情时切到 `全文总结`，生成四段总结档案并自动切回 `续写故事`。
  - **其他**：`预填充思考` 会在关闭 `输出思考面板` 时自动隐藏（部分模型开启它会强制直接进入思考，遇 `400` 报错关掉即可）。

### 2. 参数设置、正则整理与助手外观
- **参数设置**：内置 `Gemini4-low`、`Gemini4-high`、`Claude`、`DeepSeek` 四套常用参数方案，并带一键「清零惩罚项」和「恢复默认」——调这些参数**绝对不会修改你的提示词开关，也不会把长上下文窗口改小**。
- **正则设置（12 条内置，绝不篡改聊天存档）**：
  - **美化设置（7 条）**：把思考面板、状态栏、批注、小结、总结、剧情选项渲染为独立卡片，并对正文对白与分割线自动高亮；
  - **其他设置（5 条）**：隐藏正文最末尾的完结标识、发给 AI 前自动过滤掉旧回合的思考与选项卡片并定期清理过早的状态栏与长总结，还能用内置的 **禁词清洗管理器**（默认 21 条高频 AI 套话词）在发送前悄悄剔除历史套话，界面上保留原样不变。
- **助手设置**：为每位 AI 人设单独绑定悬浮球与面板主题色（没开人设时默认为琥珀色 `#c69352`），支持查看或重置悬浮球位置，以及检查预设更新。

## 三、常见问题与排错

- **看不到 `✨` 悬浮球**：请确认酒馆已安装并开启 **酒馆助手 (`JS-Slash-Runner`)**，且当前选中的预设名字正是 **`ST-PresetAssistant`**。
- **点完开关刷新网页又变回去了**：面板修改会实时作用于当前对话；确认调整满意后，记得点一次面板右上角的 **保存**。
- **对话里直接露出了 `<draft>`、`<options>` 或 `※` 原始符号**：到悬浮面板 **正则设置** 或酒馆自身正则界面检查预设附带的 7 条 `[美化]` 正则与 `隐藏完结标记` 是否处于开启状态。
- **接口报 `HTTP 400`、首字太慢或半途截断**：
  - 手动开了 `[其他] 预填充思考` 且 Gemini 4 / 严格校验接口报错时，关掉即可；
  - 搭配自带深度思考的模型觉得响应太慢，可关闭 `输出思考面板` 或把主思考换成 `叙事推理-轻量`；
  - 报错不支持惩罚参数时点 **参数设置 → 清零惩罚项**；Claude 提示 `temperature` 与 `top_p` 冲突时，在酒馆 API 连接设置里把 `top_p` 加入排除请求体参数；
  - 模型原生思考会占掉部分输出额度，建议把最大回复长度保持在 `16384`–`32768`。
