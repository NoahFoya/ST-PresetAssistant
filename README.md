# ST-PresetAssistant 预设助手

**ST-PresetAssistant**（在 SillyTavern 预设列表中显示为 **`ST-预设助手`**）是一套适用于 SillyTavern（酒馆）对话聊天补全接口的互动小说预设，内置多 AI 人设切换、模块化叙事与核心规则开关、前端四标签悬浮控制面板与全链路对话美化卡片。

---

## 运行前提与环境要求

> **基础预设功能 vs 扩展增强功能**：核心提示词规则可单独导入 SillyTavern 使用；若需启用**悬浮控制面板**、**楼层批注修改写回**及**行动建议一键填入/发送**等交互功能，需搭配安装酒馆前端扩展。

- **SillyTavern（酒馆）**：使用 Chat Completion（对话补全）模式连接模型接口。
- **酒馆助手 (`JS-Slash-Runner`)**（推荐启用）：用于运行本预设内置的悬浮控制面板、主题配色记忆与楼层消息写回功能。若尚未安装或未启用该扩展，预设的写作提示词与「思考」折叠正则仍可正常工作，但悬浮面板与卡片交互按钮将不可用。
- **正则开关保持开启**：导入预设时会附带预设内置正则脚本，请在酒馆正则面板中确认本预设相关条目处于启用状态。

## 主要功能

### 1. AI 人设与按需关闭
- **双内置 AI 人设**：内置 **`莉莉丝`**（默认开启，鬼点子多、色气十足、爱挑逗捉弄又通透体贴的雌小鬼魅魔写手）与 **`泠音`**（温润沉静、书卷气、耐心剖析且留有温度的文学编辑感创作者），并搭配核心层 **`🤝 助手确认`**（`role: assistant`）动态强化当前人设自认同与系统提示词分隔。人设条目位于提示词最上方（无额外 XML 包装），先立住角色本体再承接后续创作。
- **点按关闭与纯净接管**：再次点击当前激活的人设即可关闭，交由模型自身逻辑与当前角色卡设定主导演绎。
- **动态分组识别与条目联动**：面板严格按 **`[分组] 条目名 [单选/多选]`** 及扩展联动写法 **`[分组] 条目名 [单选/多选]&条目名称1&条目名称2`** 解析提示词（支持点击已激活项直接关闭；带 `&` 绑定时仅当任意目标条目启用才显示，为空或未匹配目标时默认显示，目标关闭导致隐藏时同步关闭该子条目并隐藏空分组；未按规则命名的条目不会在面板显示）。

### 2. 四标签页悬浮控制面板（配合酒馆助手使用）
- **自由拖拽与相对位置记忆**：收起状态下为 `42×42px` 半透明毛玻璃 **`✨` 悬浮球**（外环附带 `14s` 柔和星光环绕轨道、轻微星辉呼吸与主题光晕，悬停提示当前 AI 人设，发现 `main` 分支新版本时右上角亮起脉冲提示点），支持按住拖拽至屏幕任意位置且**不会强制吸附屏幕边缘**；展开抽屉与切换页签均采用柔和零回弹过渡，并按视口比例记忆位置。
- **四大标签页清晰分区**：
  - **「预设设置」**：严格按 `[分组] 条目名 [单选/多选]` 动态加载各分类（`AI人设`、`核心规则`、`写作规范`、`文风`、`视角`、`节奏`、`侧重`、`NSFW倾向`、`NSFW细化`、`代写边界`、`篇幅`、`功能`、`思考` 及自定义扩展分组），所有选项均支持**再次点击已激活项直接关闭**；其中 `[思考]` 分组旁附 `?` 按钮说明预填充 400 风险与思考面板定位。
  - **「参数设置」**：专责管理当前激活预设的生成参数（**绝不自动修改或联动任何提示词开关，亦不覆写或缩减你的重度长上下文上限**），顶部内置 **4 套模型方案**（`Gemini4-low` / `Gemini4-high` / `Claude` / `DeepSeek`）、`清零惩罚项` 与 `恢复默认参数`，下方支持即时微调思考深度 (`auto/low/medium/high/max`)、最大回复与最大上下文长度（tokens）、Temperature / Top-P、返回思考内容/流式开关以及高级采样与惩罚参数，各区块均配有 **`?`** 悬浮说明窗（不挤压正文排版，含 `HTTP 400` 与截断排查）。
  - **「正则设置」**：分为 **「美化设置」**（`[美化]` 前缀的 `思考 / 批注 / 选择 / 正文`）与 **「其他设置」**（不符合 `[美化]` 规则的 `历史标签过滤`、`历史禁词清洗` 及自定义正则），与酒馆原生正则列表即时同步；下方内置 **「禁词清洗」** 动态词表管理器（标题旁附 `?` 说明卡，支持实时增删词条、恢复默认并自动编译驱动 `历史禁词清洗` 正则）；
  - **「助手设置」**：集中放置 **「主题配色」**（6 组预设色调 + 自定义取色器，按当前激活 AI 人设独立保存）、**「悬浮球位置」**（查看相对坐标与一键重置默认位置）以及 **「版本与更新」**（支持页面首次加载单次 Git 更新检测并直跳 `CHANGELOG.md`，零后台轮询）。
- **即时生效与写回保存**：在面板内切换任何开关或生成参数均可实时更新当前运行中的预设状态；若希望将改动永久保存到酒馆预设存档中，点击面板右上角 **`保存`** 按钮即可同步覆盖。

### 3. 模块化叙事与创作控制
- **模块化叙事与严谨因果边界**：预设按「人设与准则 ➔ 叙事约定 ➔ 执行规则」分组，可在悬浮面板或酒馆预设提示词管理器中随时开关。内置 `<core_rules>`（聚焦虚构角色与背景下的真实沉静互动、玩家既定事实与输入模态边界、角色性格/状态变化证据强度、历史会话可信度甄别、长期连续性及自然即时叙事因果）、`<narrative_rules>` 与 `<execution_rules>` 六顺位冲突裁决，确保长对话逻辑连贯不越权。
- **写作规范切换（默认：默认 / 可选：宽松）**：`写作规范` 聚焦跨题材通用的宏观写作底线与详略节奏（细节与修饰为情绪服务、疏密随情绪曲线起伏、画面实感、反套话基线、仅实际口头台词用双引号而不误伤纯动作/意愿输入、保留有递进层次的习惯复现）；也可随时切换为 **`宽松`**（放开否定句、比喻与破折号等句法束缚，仍保持台词规范、疏密起伏、情节推进与高文本质感）。
- **文风选择（默认：情色文学）**：包含 `情色文学`（以情绪为主线、一段一感官锚点与张力/峰值/余韵三种疏密示范）、`直白肉文`（每分镜一特写、镜间换气节奏与直白感官冲击）、`写实白描`、`细腻工笔`、`轻小说体`、`轻快网感`、`古风雅韵`、`典雅书面` 共 8 款文风，各含三段语感示范，只约束语言质感与节奏而不干涉剧情走向；点按关闭时依设定自然行文。
- **叙事视角（默认：第三人称限知）**：支持 `第一人称`、`第二人称`、`第三人称限知`、`第三人称全知`，明确幕后时间线进展与当前视角见闻准入边界。
- **剧情节奏（默认：张弛自然）**：支持 `慢笔细写`、`张弛自然`、`紧凑推进`、`快进略写` 四档故事时间流速与详略调度。
- **描写侧重（默认：均衡全面）**：支持 `均衡全面`、`对话交锋`、`动作神态`、`心理刻画`、`环境烘托` 五类写作重心，顺应节奏详略协调呈现。
- **NSFW 倾向与细化（默认全关）**：
  - `NSFW 倾向` 为可选互斥单选（`通用` / `男性向` / `女性向`，再次点击已选项可取消关闭），以感受落点与互动回馈取代阶段清单，区分通用双视角交互、男性向主导感与双向感受、女性向被珍视感与铺垫张力；
  - `NSFW 细化` 提供独立的 `反应多样性` 开关，用于丰富不同性格角色在亲密互动中的差异化反应。
- **代写边界分级（默认：禁止代写）**：提供 `禁止代写`（仅顺承必需物理体感与衔接，不代写 `{{user}}` 未表达的情绪与抉择）、`允许延伸`（贴合人设适度顺延动作与微反应，不替 `{{user}}` 做关键决策）与 `自由代写`（自主推进与立体刻画，节点适时留白），与 `<core_rules>` 既定事实保护解耦协作；全关时交由模型自然把握。
- **目标篇幅（默认：适中 800-1200 字）**：提供 `较短 (400-800字)`、`适中 (800-1200字)`、`较长 (1200-1800字)` 三档参考目标，以场景完整性、互动连贯与情绪节奏优先；关闭全部选项时不再暗含隐藏字数限制。
- **功能开关与思考设置**：支持按需开关 `正文批注`（独立伴读层，支持点评、自省、吐槽与伏笔备忘，不串入正文口吻亦不覆写既定事实）、`行动选项`（去模板化生成不同风格或不同作用的实质行动分支，开放提问时自然留白）、`格式兼容`（严格隔离正文、结构化标签与附加输出层级）、`防复读检查`（默认关闭，跨回合结构与语义破局审计），以及默认双开完整执行的 `构思推演`、`输出思考面板` 与可选 `预填充思考`。

### 4. 对话楼层美化与上下文清洗（6 条内置正则）
- **`[美化] 思考`**：将 AI 正文前的 `<draft>...</draft>` 推理分析自动折叠收纳为「**思考**」（`推演过程`）卡片，与原生英文思考标签（`<think>` / `<thinking>`）互不冲突，保持聊天界面整洁。
- **`[美化] 批注`**：将正文中独立成行的 `※ 署名：……` 渲染为默认收起的「**批注**」卡片（闭合态仅显示单行首楼预览与楼层数，保持正文阅读连贯；自动识别自定义 `[AI人设]` 作者与自定义读者署名），点击标题栏或箭头展开后可对任意楼层直接 **编辑** 或 **删除**，也可在署名框直接选择 `master` / `正文批注` 或输入并记忆自定义署名 **追加** 记录写回正文；已针对移动端做防缩放输入框与窄屏自动换行适配。
- **`[美化] 选择`**：将文末 `<options>...</options>` 渲染为可点击「**选择**」卡片，提供 **填入**（填入输入框等待补充修改）和 **发送**（填入后立即发送）两种模式，并自动记住上次选用的输入模式。
- **`[美化] 正文`**：随酒馆当前主题色自动润色正文中的中文对白（`“……”` / `「……」`）与场景分割线（`---` / `***` / `===`），并严格跳过构思面板、批注楼与选择卡片内部文本。
- **`历史标签过滤`**：归于正则「其他设置」，发送消息给模型前自动剔除历史消息中的 `<draft>` 与 `<options>` 标签内容，保留 `※` 批注行作为长期记忆承接。
- **`历史禁词清洗`**：归于正则「其他设置」（默认开启），由悬浮面板「禁词清洗」词表动态编译驱动；仅在发送给模型前从 AI 历史回复中剔除指定套话词汇（不修改聊天存档与界面显示），用于切断上下文复读传染。

## 获取、安装与升级方法

### 初次安装步骤
1. **下载预设文件**：前往本仓库 [`presets/`](presets/) 目录（或 [GitHub Releases](https://github.com/NoahFoya/ST-PresetAssistant/releases)）下载最新的编译预设 JSON 文件（当前为 [`presets/ST-PresetAssistant_V0.5.0.json`](presets/ST-PresetAssistant_V0.5.0.json)）。
2. **导入 SillyTavern**：打开 SillyTavern 顶部 **AI 响应配置（预设 / Presets）** 面板，点击导入按钮，选择下载的 JSON 文件；导入后在预设下拉列表中选择 **`ST-预设助手`** 启用。
3. **检查伴随开关**：确保已在扩展中安装并开启 **酒馆助手 (`JS-Slash-Runner`)**，并保持本预设自带的内置正则与脚本处于开启状态，刷新页面后即可在界面上看到半透明 `✨` 悬浮球。

### 后续版本升级
本预设在酒馆内部的导入名称固定为 **`ST-预设助手`**（不包含版本号后缀）。当后续发布新版时，下载新版 JSON 文件直接导入预设面板并选择覆盖原 **`ST-预设助手`** 即可完成升级，不会在下拉列表中产生多个重复条目。

## 初次使用快速配置

1. **选择 AI 人设（或再次点击关闭）**：点击界面上的半透明 **`✨`** 悬浮球展开面板，在「预设设置」标签页的「AI人设」中选择 `莉莉丝`、`泠音`，或再次点击已激活项将其关闭、完全交给角色卡自行演绎。
2. **设定核心规则、写作规范与文风**：在动态分组的各栏目中点选配置；也可随时切换至「正则设置」开关思考/批注/选择/正文美化规则及其他过滤规则，或前往「助手设置」调整主题配色与悬浮球位置。
3. **按需调整附加功能**：
   - 如使用自带推理能力的推理模型（Thinking / Reasoning 模型），可在「思考」中关闭 `输出思考面板`，避免双重推演；
   - 如不需要在正文段落间看到 `※` 批注，或不需要文末 `行动选项`，可在「功能」中随时点击关闭。
4. **保存当前组合**：所有在面板中的点选都会实时生效于当前会话，调整到满意组合后点击右上角 **`保存`**，即可将该配置写入酒馆本地存储的预设文件中长期保留。

## 常见问题与排障 (FAQ)

### 1. 导入预设后，页面上看不到 `✨` 悬浮球或控制面板？
- **确认酒馆助手状态**：请检查 SillyTavern 扩展列表是否已安装并启用 **酒馆助手 (`JS-Slash-Runner`)**，且版本支持运行预设内嵌脚本。
- **确认当前已选中预设**：悬浮脚本随预设 **`ST-预设助手`** 激活生效，请确认当前对话补全预设栏选中的正是该预设。
- **排查遮挡**：首次加载时悬浮球位于屏幕靠右上方区域；若窗口尺寸较小可缩小/放大浏览器窗口或查看页面右侧边缘。

### 2. 在悬浮面板里改了开关，刷新页面或重开酒馆后又变回默认设置？
- 在面板中点击条目只会实时修改内存中的**当前启用预设状态 (`in_use`)**，方便在单次游玩中临时试调参数；若要让新设置永久写入你的本地预设存档，请在调整完毕后点击面板右上角的 **`保存`** 按钮，看到底部提示「已保存至预设」即表示落盘成功。

### 3. 对话中只显示了 `<draft>` 或 `※` 原始文字，没有变成折叠面板或楼层卡片？
- 请先展开悬浮面板切到 **「正则设置」** 标签页，或进入 SillyTavern **正则（Regex）** 面板，确认预设附带的 `[美化] 思考`、`[美化] 批注`、`[美化] 选择`、`[美化] 正文` 均处于开启状态。
- 历史楼层中的 `<draft>` 与 `<options>` 由 `历史标签过滤` 规则在发送给模型前自动过滤，避免占满上下文；正文中原有的 `※` 行会保留供后续对话参考。

### 4. 如何彻底关闭预设内的「AI人设」，只按角色卡原味输出？
- 在悬浮面板「预设设置 ➔ AI人设」一栏直接**再次点击当前激活的人设**将其熄灭（或在酒馆预设条目列表中关闭所有 `[AI人设]` 开头的条目）后点击 **`保存`**。此时预设不会注入任何 AI 人设性格定义，其余规则仍继续生效。

### 5. 使用 Gemini 4 / Claude 等模型时遇到 `HTTP 400` 报错或输出中途截断？
- **末尾预填充 `400`**：Gemini 4、部分推理模型与严校验中转不支持请求以 `Assistant` 消息结尾；若你在「预设设置 → 思考」手动开启了 `预填充思考`，将其关闭即可。
- **惩罚或采样互斥 `400`**：部分 Gemini / Vertex 端点不支持频率惩罚、存在惩罚或 `Min-P`，可在悬浮面板 **「参数设置」** 点击 **「清零惩罚」**；若 Claude 新版模型报 `temperature and top_p cannot both be specified`，请在酒馆 API 连接设置「排除请求体参数 (Exclude Body Parameters)」中添加 `top_p`。
- **回复截断或思考过长**：内置思维链消耗「回复上限」，长文建议在「参数设置」保持 `16384`–`32768`；若 Gemini 4 正文出现过度说教或强行升华，可切换至 **`Gemini4-low`**。
