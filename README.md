# ST-PresetAssistant 预设助手

**ST-PresetAssistant**（在 SillyTavern 预设列表中显示为 **`ST-预设助手`**，当前版本 **`v1.0.0`**）是一套适用于 SillyTavern 对话补全模式的互动小说预设，内置多 AI 人设切换、模块化写作与交互规则开关、四页签悬浮控制面板以及对话卡片美化。

---

## 一、使用说明（快速上手）

### 1. 环境要求
- **SillyTavern（酒馆）**：使用 Chat Completion（对话补全）模式连接模型接口。
- **酒馆助手 (`JS-Slash-Runner`)**（推荐启用）：用于运行悬浮控制面板、主题配色记忆、批注写回与选项快捷填入功能。未安装该扩展时，预设写作规则与基础正则仍可正常使用，但悬浮面板与卡片交互按钮不可用。
- **内置正则保持开启**：导入预设时会附带 12 条内置正则，请保持它们处于启用状态。

### 2. 安装与升级
1. **下载预设**：在仓库根目录下载最新的 [`ST-PresetAssistant_V1.0.0.json`](ST-PresetAssistant_V1.0.0.json)（历史正式版本归档于 [`history/`](history/)）。
2. **导入启用**：打开 SillyTavern 顶部 **AI 响应配置（预设）** 面板导入 JSON 文件，并在下拉列表中选择 **`ST-预设助手`**。
3. **版本升级**：预设在酒馆内的名称固定为 **`ST-预设助手`**。后续升级直接导入新版 JSON 并覆盖原预设即可，不会产生重复条目。

### 3. 开箱默认配置与日常操作
导入后无需繁琐配置即可直接使用，点击界面半透明 **`✨`** 悬浮球即可随时微调（可自由拖拽至屏幕任意位置，满意后点右上角 **保存** 永久写入预设存档）：

- **默认提示词组合**：`莉莉丝：肉文写手` + `情色文学` + `中性双向` + `第三人称限知` + `张弛自然` + `自然均衡` + `适中 (800-1200字)` + `标准`写作规范 + `直接承接` + `有限延伸` + `叙事推理-重度` + `输出思考面板` + `剧情选项` + `外部格式兼容` + `[核心任务] 续写故事`（`正文批注` 默认关闭，开启后每轮稳定产出 1~2 条批注；若需切换全年龄/日常向，只需在面板切至 `经典日轻 / 新式轻文学 / 细腻工笔` 等文风并关闭 `[NSFW倾向]` 即可）。
- **默认模型参数**：对齐 `Gemini4-high` 实测配置（`reasoning_effort: high`、最大回复长度 `32768`、最大上下文 `2000000`、`temperature: 1.0`、`top_p: 1.0`、各项惩罚为 `0`）。
- **四页签悬浮控制面板**：
  - **预设设置**：按「基础与输出目标 / 执行与思考体系 / 附加输出与核心任务」三层排布，所有单选按钮再次点击即可关闭。
  - **参数设置**：内置 `Gemini4-low`、`Gemini4-high`、`Claude`、`DeepSeek` 四套参数方案，支持一键清零惩罚项、恢复默认参数与微调采样/推理深度（绝不改写提示词开关，也不会缩减你的长上下文上限）。
  - **正则设置**：分「美化设置」与「其他设置」两组独立开关，并内置「禁词清洗」动态词表管理器（默认内置 21 条低误伤套话修饰词及词形变体）。
  - **助手设置**：按当前激活人设独立保存主题配色、查看或重置悬浮球位置，以及检查新版本更新。

### 4. 常见问题与排错
- **看不到 `✨` 悬浮球**：请确认已安装并启用 **酒馆助手 (`JS-Slash-Runner`)**，且当前选中的预设为 **`ST-预设助手`**。
- **改了开关刷新后失效**：面板中的修改即时生效于当前会话；调整满意后请点击面板右上角 **保存** 写入预设存档。
- **对话只显示原始标签未渲染卡片**：请到悬浮面板 **正则设置** 或 SillyTavern 正则面板确认预设附带的 7 条 `[美化]` 正则与 `隐藏完结标记` 均已开启。
- **Gemini 4 / Claude 报 `HTTP 400`、首字偏慢或输出截断**：
  - 若手动开启了 `[思考工具] 预填充思考` 并报 `400`，将其关闭即可；
  - 若搭配原生思考模型且上下文较长，感觉首字偏慢或双重思考冗长，可关闭 `[思考工具] 输出思考面板` 或将 `[主思考]` 切至 `叙事推理-轻量`；
  - 部分接口不支持惩罚参数时，可在 **参数设置** 点击 **清零惩罚项**；若 Claude 报 `temperature` 与 `top_p` 互斥，请在酒馆 API 连接的「排除请求体参数」中填入 `top_p`；
  - 内置思考会占用回复额度，建议将最大回复长度保持在 `16384`–`32768`。

## 二、预设机制说明（按需查阅）

以下内容面向希望深入了解预设内部结构、精细调优或二次扩展的用户，日常使用可按需查阅。

### 1. 多 AI 人设、六层全 `system` 规则流与尾部 `<core_task>`
- **三位内置人设**：全仓统一为「玩家（`user`）↔ `Assistant`」唯一对话双主体，三位人设仅在性格气质与创作关注点上各有侧重（采用规范化 3 条特质、不设固定口癖示例）——**`莉莉丝：肉文写手`**（默认开启，直爽敏锐带轻度俏皮，擅长成人向情感张力与情欲故事）、**`泠音：剧情小说`**（温和沉静、条理清晰，擅长剧情脉络与人物动因）、**`Ark：角色扮演`**（冷静理性、观察细致，擅长世界规则自洽、角色扮演与世界构建）。
- **双节点 `Assistant` 重锚 + 无伪对话干扰**：各人设开篇明确唯一身份为「玩家（`user`）的 `Assistant`」，在 `<core_rules>`（前置立责）与 `<execution_rules>`（历史后执行收束，含 7 级规则优先级且明确 `叙事视角` 高于文风与专项描写）两处关键边界以「要求 Assistant」重锚指令强度，`<narrative_rules>` 保持纯客观创作规范直出；移除历史伪确认回合后，故事设定与历史会话明确区分资料来源，动态叙事与执行配置置于 `<chat_history>` 之后（使规则靠近生成位置，且切换文风/视角时不破坏前部稳定前缀），避免内部消息干扰玩家真实输入判断。
- **尾置 `[核心任务]` 单选组（`<core_task>`，`role: user`）**：按任务阻力差异化直述且不带客套语——默认开启 **`续写故事`**（直接祈使紧接最新处续写，兼顾有玩家输入、无输入续写与中途接续，并在请求末尾提供安全 `user` 意图缓冲）；长对话需阶段整理时切换至 **`全文总结`**（显式要求 `Assistant` 暂停续写并直接输出四段 `<recap>` 总结档案与完结标记，生成结束后自动切回 `续写故事`）。
- **纯净接管与自定义扩展**：在悬浮面板点击当前激活的人设即可关闭全部人设，自动以纯净 `Assistant` 身份承接；自建 `[AI人设]` 只需说明自身是「玩家（`user`）的 `Assistant`」即可无缝接入，无需手写宏变量。正文叙事始终与人设腔调隔离，严守故事自身背景与口吻。

### 2. 分层提示词体系与「准则 / 思维链」分离机制
- **动态分组与 `&` 联动**：面板自动识别 `[分组] 条目名 [单选/多选]` 与 `[分组] 条目名 [单选/多选]&目标1&目标2` 命名格式；带 `&` 绑定的子项仅当任一目标启用时显示，目标全部关闭时自动隐藏并停用。
- **三大功能层分工**：
  - **基础与输出目标层**：`AI人设`、`核心规则`（确立面向成人的虚构互动文学边界、五类输入性质判定、角色独立防迎合、认知盲区隔离、静态设定免复述、人物设定隐性化、有效推进与自然留白）、`视角`、`文风`（经典日轻、新式轻文学、细腻工笔、情色文学、直白肉文、爽利网文、写实白描、古风雅韵、严肃正剧共 9 款，默认 `情色文学`，按场景调节感官密度）、`节奏`、`侧重`（自然均衡、对话交锋、动作神态、外貌神韵、心理刻画、环境烘托共 6 款，依场景自然侧重）、`篇幅`（信息量驱动的弹性参考，低信息回合主动短收）、`写作规范`（标准 / 宽松，聚焦词句自然简洁、近几轮语义去重与直接引语）与 `NSFW倾向`（中性双向 / 男性向 / 女性向，默认 `中性双向`，兼容各种性别组合并聚焦可观察互动反差）/`NSFW细化`（反应多样性）；
  - **执行与思考体系层**：`输入处理`（`直接承接 / 演绎展开`，默认 `直接承接`）、`代写边界`（`禁止代写 / 有限延伸 / 自由代写`，默认 `有限延伸`）、`主思考`（叙事推理-重度 / 叙事推理-轻量，单选互斥，默认 `叙事推理-重度`，按五类输入与状态差分条件推导）、`思考增强`（多角色调度、心理潜台词、伏笔与暗线、防谄媚读心、防复读套话，均默认关闭，开启后每轮先核查、条件不成立时推演记“无”，建议按场景选开 1~2 项）与 `思考工具`（`输出思考面板` 默认开、完整显化全部已启用思考步骤便于排查，`预填充思考` 默认关）；
  - **附加输出与核心任务层**：`附加输出`（`场景状态栏`、`正文批注` 默认关且开启必出 1~2 条、`场景小结`、`剧情选项`、`外部格式兼容`，按实际生成时序排布）与 `核心任务`（`续写故事` 默认开 / `全文总结` 默认关，单选互斥）。

### 3. 对话美化与上下文整理机制（12 条内置正则）
- **美化设置（7 条，仅作用于显示层）**：将 `<draft>` 思考过程、`<scene>` 场景状态栏（时间｜地点｜在场人物）、`※ 标签：内容` 正文批注（支持快捷/自定义标签添加与全楼层编辑删除）、`<summary>` 场景小结、`<recap>` 全文总结档案以及 `<options>` 文末剧情选项（支持跨轮差异化角色动向与时间推进、转场、临时切视角、留白静观等叙事功能项，点击填入保留原有草稿换行追加）渲染为独立界面卡片，并对正文对白（`“...”` / `「...」` / `『...』` 及行内斜体/加粗）与分割线进行润色；各正则均具备闭合与流式未闭合 `<draft>` 隔离保护。
- **其他设置（5 条，均默认开启）**：
  - **`隐藏完结标记`（显示层）**：自动隐藏回复最末尾的 `<ToBeContinue>` 完结标记（排错时可一键关闭核验模型输出完整性，同时保护 `<draft>` 内与正文行内提及不被误删）。
  - **`历史标签过滤`（发送前）**：发给模型前实时剔除历史旧回复中的 `<draft>`、`<options>` 与 `<ToBeContinue>`，不改聊天存档。
  - **`历史状态栏清理` / `历史总结清理`（发送前按深度）**：自动清理 6 层以前的 `<scene>` 与 30 层以前的 `<recap>`，避免长对话旧定格画面互相干扰；`※` 批注、伏笔与 `<summary>` 随历史持久留存。
  - **`历史禁词清洗`（发送前）**：默认开启 21 条低误伤套话修饰词及词形变体表（长词优先编译防残句），仅在发给模型前从 AI 历史回复中剔除，不改聊天记录与界面显示，可在悬浮面板自由增删词条。
