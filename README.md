# ST-PresetAssistant 预设助手 (`v0.3.0`)

**ST-PresetAssistant**（中文简称：**ST-预设助手**）是一套面向 **SillyTavern（酒馆）** 的多助手人设互动小说预设与前端控制台套件，采用 **6 大 XML 语义块 + 非 JSON 源码驱动闭环**，内嵌基于 **酒馆助手 (`JS-Slash-Runner`)** 的悬浮控制面板与可编辑全楼层交互卡片。

> **项目仓库**：`https://github.com/NoahFoya/ST-PresetAssistant`

---

## 核心特性

1. **多助手人设与「不启用」无干扰兼容**：
   - 内置 **`[人设] 莉莉丝`**（初始默认开启，搭配 `[文风] 情色文学`）与 **`[人设] 泠音`**，支持在控制面板一键切换为 **`不启用`**（由模型自身或外部角色设定自然接管），并自动发现自定义人设条目；
   - 全套件条目统一采用 `[分类] 选项名` 极简命名，底层顺序与控制面板 1:1 对齐 **`核心规则 -> 叙事约定 -> 执行规则`**。
2. **文学化叙事控制与双轨 NSFW 分组**：
   - **8 款通用第三人称文风**、**顺序视角**（`第一人称 / 第二人称 / 第三人称限知(默认) / 第三人称全知`）、**文学节奏**（`慢笔细写 / 张弛自然(默认) / 紧凑推进 / 跳场略写`）与 **五维描写侧重**（`均衡全面(默认) / 对话交锋 / 动作神态 / 心理刻画 / 环境烘托`）；
   - **`[NSFW倾向]`**（无倾向 / 男性向 / 女性向，单选互斥且可点灭，默认全关）与 **`[NSFW细化]`**（反应多样性，独立可叠加开关）；
   - **`[思考] 基本推理`** 作为主思考链条目，为后续可扩展的子推理模块预留清晰归类位置。
3. **酒馆助手悬浮控制面板（`floating_panel.js`）**：
   - 支持**二维自由拖拽与视口相对位置记忆**（不贴边强制吸附），点击胶囊就近在当前位置展开面板；
   - 顶栏标题稳定显示 **`ST-预设助手`** + 单枚 **`vX.Y.Z`** 版本徽标；导入预设固定名为 `ST-预设助手`，升级版本不产生重复预设副本；
   - 支持按当前激活人设绑定保存主题配色（6 组预设色调 + 自定义取色），即时写入预设并支持顶部「保存」同步写回酒馆预设列表。
4. **全楼层可编辑随记批注与正则隔离**：
   - 统一 `※ 署名：……` 段间格式并完整保留于历史上下文；配合正则卡片开放**全楼层「编辑 / 删除」与底部「追加」**，支持直接修改 AI 伏笔记录并写回消息本体；
   - `<draft>` 构思手记、`※` 段间批注与 `<options>` 行动建议严格互不干扰。

## 快速使用

1. 在 SillyTavern 中安装并启用扩展 **酒馆助手 (`JS-Slash-Runner`)**。
2. 下载并导入最新编译产物：`presets/ST-PresetAssistant_preset_v0.3.0.json`。
3. 如需开启悬浮控制面板或楼层写回，保持预设内置酒馆助手脚本与正则脚本启用即可。

## 本地开发、构建与 Git 工作流

本项目遵循 **非 JSON 源码驱动闭环（Source -> Sync & Compile -> Verify -> Docs）**，源码全部维护在 `raw_data_cache/` 下：

```powershell
# 进入套件目录后运行全链路构建、8 项静态/V8 单测校验与文档生成
npm run all
```

- **分支规划**（对标 `ST-DrawAssistant`）：
  - `main`：稳定发布主干分支，每次正式发版同步打上 `vX.Y.Z` Git Tag。
  - `dev`：日常开发与提示词/UI 调优分支，通过 `npm run all`（`Errors: 0`）并完成预览验证后合并回 `main`。
