# ST-PresetAssistant 预设助手

**ST-PresetAssistant**（在 SillyTavern 预设列表中显示为 **`ST-预设助手`**）是一套适用于 SillyTavern（酒馆）对话聊天补全接口的互动小说预设，内置多助手人设切换、模块化叙事开关、前端悬浮控制面板与对话楼层交互卡片。

---

## 运行前提与环境要求

> **基础预设功能 vs 扩展增强功能**：核心提示词规则可单独导入 SillyTavern 使用；若需启用**悬浮控制面板**、**楼层批注修改写回**及**行动建议一键填入/发送**等交互功能，需搭配安装酒馆前端扩展。

- **SillyTavern（酒馆）**：使用 Chat Completion（对话补全）模式连接模型接口。
- **酒馆助手 (`JS-Slash-Runner`)**（推荐启用）：用于运行本预设内置的悬浮控制面板、主题配色记忆与楼层消息写回功能。若尚未安装或未启用该扩展，预设的写作提示词与「构思手记」折叠正则仍可正常工作，但悬浮面板与卡片交互按钮将不可用。
- **正则开关保持开启**：导入预设时会附带预设内置正则脚本，请在酒馆正则面板中确认本预设相关条目处于启用状态。

## 主要功能

### 1. 助手人设与纯净接管
- **双内置助手人设**：内置 **`莉莉丝`**（默认开启，偏向热烈张力与直爽点评）与 **`泠音`**（偏向克制细腻与长线伏笔）。
- **不启用模式**：可在面板切换为 **`不启用`**，此时预设不注入任何预设助手人设，交由模型自身逻辑与当前角色卡设定主导演绎。
- **自定义人设识别**：如你在预设内自行添加了标识为 `[人设] 名称` 的提示词条目，悬浮面板会自动识别并纳入人设切换栏。

### 2. 悬浮控制面板（配合酒馆助手使用）
- **自由拖拽与相对位置记忆**：收起状态下为轻量悬浮胶囊（显示当前激活人设），支持按住拖拽至屏幕任意位置且**不会强制吸附屏幕边缘**；系统按视口比例记忆位置，刷新页面或调整窗口大小时按比例保留位置。
- **人设专属主题配色**：点击胶囊就近展开设置面板后，可在「主题配色」中点击色点或使用自定义取色器调节面板强调色；颜色配置会自动绑定到当前所选的助手人设，切换不同人设时自动切换各自配色。
- **即时生效与写回保存**：点击面板内的各组选项可立即更新当前运行中的预设状态；若希望将改动永久保存到酒馆预设文件中，点击面板右上角 **`保存`** 按钮即可同步覆盖。
- **首次加载更新检测与日志直跳**：面板每次页面首次加载时会向 GitHub 检查一次最新版本号（后续不进行后台轮询）。发现新版本时，顶栏版本徽标会高亮提示；点击版本徽标即可直接前往仓库的 `CHANGELOG.md` 页面查看更新说明与新版下载信息。

### 3. 模块化叙事与创作控制
预设按「人设与准则 ➔ 叙事约定 ➔ 执行规则」分组，可在悬浮面板或酒馆预设提示词管理器中随时开关：
- **文风选择（默认：情色文学）**：包含 `情色文学`、`肉文直白`、`写实白描`、`细腻工笔`、`轻小说体`、`轻快网感`、`古风雅韵`、`典雅书面` 共 8 款第三人称示范文风。
- **叙事视角（默认：第三人称限知）**：支持 `第一人称`、`第二人称`、`第三人称限知`、`第三人称全知`。
- **剧情节奏（默认：张弛自然）**：支持 `慢笔细写`、`张弛自然`、`紧凑推进`、`跳场略写` 四档叙事详略调度。
- **描写侧重（默认：均衡全面）**：支持 `均衡全面`、`对话交锋`、`动作神态`、`心理刻画`、`环境烘托` 五类写作重心。
- **NSFW 倾向与细化（默认全关）**：
  - `NSFW 倾向` 为可选互斥单选（`无倾向` / `男性向` / `女性向`，再次点击已选项可取消关闭）；
  - `NSFW 细化` 提供独立的 `反应多样性` 开关，用于丰富不同性格角色在亲密互动中的差异化反应。
- **目标篇幅（默认：中篇 800-1200 字）**：提供 `短篇 (400-800字)`、`中篇 (800-1200字)`、`长篇 (1200-1800字)` 三档，并联动控制每轮段间随记的数量范围。
- **功能开关与思考设置**：支持按需开关 `段间随记批注`、`行动选项`、`剧情防重复`、`格式兼容`，以及 `基本推理`、`输出草稿面板`、`预填充草稿 (Prefill)`。

### 4. 对话楼层交互卡片
- **构思手记折叠**：将 AI 正文前的 `<draft>...</draft>` 推理草稿自动折叠收纳为「构思手记」面板，保持聊天界面整洁。
- **段间随记与批注楼**：将正文中独立成行的 `※ 署名：……` 渲染为可视化楼层卡片，支持点击任意楼层（包括 AI 写下的伏笔随记与读者评论）直接 **编辑** 或 **删除**，也可在底部输入框选择 `master` 或 `伏笔随记` 署名 **追加** 记录，并写回该条消息正文供后续对话承接。
- **行动方向建议**：将文末 `<options>` 渲染为可点击卡片，提供 **填入**（填入输入框等待补充修改）和 **发送**（填入后立即发送）两种模式。

## 获取、安装与升级方法

### 初次安装步骤
1. **下载预设文件**：前往本仓库 [`presets/`](presets/) 目录（或 [GitHub Releases](https://github.com/NoahFoya/ST-PresetAssistant/releases)）下载最新的编译预设 JSON 文件（当前为 [`presets/ST-PresetAssistant_preset_v0.1.0.json`](presets/ST-PresetAssistant_preset_v0.1.0.json)）。
2. **导入 SillyTavern**：打开 SillyTavern 顶部 **AI 响应配置（预设 / Presets）** 面板，点击导入按钮，选择下载的 JSON 文件；导入后在预设下拉列表中选择 **`ST-预设助手`** 启用。
3. **检查伴随开关**：确保已在扩展中安装并开启 **酒馆助手 (`JS-Slash-Runner`)**，并保持本预设自带的内置正则与脚本处于开启状态，刷新页面后即可在界面上看到悬浮胶囊。

### 后续版本升级
本预设在酒馆内部的导入名称固定为 **`ST-预设助手`**（不包含版本号后缀）。当后续发布新版时，下载新版 JSON 文件直接导入预设面板并选择覆盖原 **`ST-预设助手`** 即可完成升级，不会在下拉列表中产生多个重复条目。

## 初次使用快速配置

1. **选择助手人设（或切换为不启用）**：点击悬浮胶囊 **`预设助手 · 莉莉丝`** 展开面板，根据当前想玩的角色卡与文风需求，在「助手人设」中选择 `莉莉丝`、`泠音`，或选择 `不启用` 以完全交给角色卡自行演绎。
2. **设定基础文风与视角**：在「文风」「叙事视角」「剧情节奏」「描写侧重」「目标篇幅」中点选习惯的阅读配置；首次使用可先保持默认设置试跑几轮对话。
3. **按需调整附加功能**：
   - 如使用自带推理能力的推理模型（Thinking / Reasoning 模型），可在「思考与草稿」中关闭 `输出草稿面板`，避免双重推演；
   - 如不需要在正文段落间看到 `※` 随记批注，或不需要文末 `行动选项`，可在「功能开关」中随时点击关闭。
4. **保存当前组合**：所有在面板中的点选都会实时生效于当前会话，调整到满意组合后点击右上角 **`保存`**，即可将该配置写入酒馆本地存储的预设文件中长期保留。

## 常见问题与排障 (FAQ)

### 1. 导入预设后，页面上看不到悬浮胶囊或控制面板？
- **确认酒馆助手状态**：请检查 SillyTavern 扩展列表是否已安装并启用 **酒馆助手 (`JS-Slash-Runner`)**，且版本支持运行预设内嵌脚本。
- **确认当前已选中预设**：悬浮脚本随预设 **`ST-预设助手`** 激活生效，请确认当前对话补全预设栏选中的正是该预设。
- **排查遮挡**：首次加载时胶囊位于屏幕靠右上方区域；若窗口尺寸较小可缩小/放大浏览器窗口或查看页面右侧边缘。

### 2. 在悬浮面板里改了开关，刷新页面或重开酒馆后又变回默认设置？
- 在面板中点击条目只会实时修改内存中的**当前启用预设状态 (`in_use`)**，方便在单次游玩中临时试调参数；若要让新设置永久写入你的本地预设存档，请在调整完毕后点击面板右上角的 **`保存`** 按钮，看到底部提示「已保存至预设」即表示落盘成功。

### 3. 对话中只显示了 `<draft>` 或 `※` 原始文字，没有变成折叠面板或楼层卡片？
- 请进入 SillyTavern **正则（Regex）** 面板，确认预设附带的 `💭 构思手记折叠`、`💬 段间随记与批注卡片`、`🎯 行动选项交互卡片` 等条目未被手动禁用，且未与外部第三方全局同名正则规则冲突。
- 历史楼层中的 `<draft>` 与 `<options>` 由 `🧹 历史手记与选项清洗` 规则在发送给模型前自动过滤，避免占满上下文；正文中原有的 `※` 行会保留供后续对话参考。

### 4. 如何彻底关闭预设内的「助手人设」，只按角色卡原味输出？
- 在悬浮面板「助手人设」一栏点击 **`不启用`**（或在酒馆预设条目列表中关闭所有 `[人设]` 开头的条目）后点击 **`保存`**。此时预设不会注入任何助手性格定义，所有基础创作准则与写作开关仍继续生效。
