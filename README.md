# ST-PresetAssistant 预设助手

**ST-PresetAssistant**（在 SillyTavern 预设列表中显示为 **`ST-预设助手`**，当前版本 **`v0.9.0`**）是一套适用于 SillyTavern 对话补全模式的互动小说预设，内置多 AI 人设切换、模块化写作与交互规则开关、四页签悬浮控制面板以及对话卡片美化。

---

## 一、使用说明（快速上手）

### 1. 环境要求
- **SillyTavern（酒馆）**：使用 Chat Completion（对话补全）模式连接模型接口。
- **酒馆助手 (`JS-Slash-Runner`)**（推荐启用）：用于运行悬浮控制面板、主题配色记忆、批注写回与选项快捷填入功能。未安装该扩展时，预设写作规则与基础正则仍可正常使用，但悬浮面板与卡片交互按钮不可用。
- **内置正则保持开启**：导入预设时会附带 12 条内置正则，请保持它们处于启用状态。

### 2. 安装与升级
1. **下载预设**：在仓库根目录下载最新的 [`ST-PresetAssistant_V0.9.0.json`](ST-PresetAssistant_V0.9.0.json)（历史正式版本归档于 [`history/`](history/)）。
2. **导入启用**：打开 SillyTavern 顶部 **AI 响应配置（预设）** 面板导入 JSON 文件，并在下拉列表中选择 **`ST-预设助手`**。
3. **版本升级**：预设在酒馆内的名称固定为 **`ST-预设助手`**。后续升级直接导入新版 JSON 并覆盖原预设即可，不会产生重复条目。

### 3. 开箱默认配置与日常操作
导入后无需繁琐配置即可直接使用，点击界面半透明 **`✨`** 悬浮球即可随时微调（可自由拖拽至屏幕任意位置，满意后点右上角 **保存** 永久写入预设存档）：

- **默认提示词组合**：`莉莉丝：肉文写手` + `情色文学` + `中性双向` + `第三人称限知` + `张弛自然` + `均衡全面` + `适中 (800-1200字)` + `标准`写作规范 + `直接承接` + `有限延伸` + `叙事推理-重度` + `输出思考面板` + `正文批注` + `剧情选项` + `外部格式兼容`（若需切换全年龄/日常向，只需在面板切至 `经典日轻 / 新式轻文学 / 细腻工笔` 等文风并关闭 `[NSFW倾向]` 即可）。
- **默认模型参数**：对齐 `Gemini4-high` 实测配置（`reasoning_effort: high`、最大回复长度 `32768`、最大上下文 `2000000`、`temperature: 1.0`、`top_p: 1.0`、各项惩罚为 `0`）。
- **四页签悬浮控制面板**：
  - **预设设置**：按「基础与输出目标 / 执行与思考体系 / 附加输出与总结」三层排布，所有单选按钮再次点击即可关闭。
  - **参数设置**：内置 `Gemini4-low`、`Gemini4-high`、`Claude`、`DeepSeek` 四套参数方案，支持一键清零惩罚项、恢复默认参数与微调采样/推理深度（绝不改写提示词开关，也不会缩减你的长上下文上限）。
  - **正则设置**：分「美化设置」与「其他设置」两组独立开关，并内置「禁词清洗」动态词表管理器。
  - **助手设置**：按当前激活人设独立保存主题配色、查看或重置悬浮球位置，以及检查新版本更新。

### 4. 常见问题与排错
- **看不到 `✨` 悬浮球**：请确认已安装并启用 **酒馆助手 (`JS-Slash-Runner`)**，且当前选中的预设为 **`ST-预设助手`**。
- **改了开关刷新后失效**：面板中的修改即时生效于当前会话；调整满意后请点击面板右上角 **保存** 写入预设存档。
- **对话只显示原始标签未渲染卡片**：请到悬浮面板 **正则设置** 或 SillyTavern 正则面板确认预设附带的 7 条 `[美化]` 正则与 `隐藏完结标记` 均已开启。
- **Gemini 4 / Claude 报 `HTTP 400`、首字偏慢或输出截断**：
  - 若手动开启了 `[思考工具] 预填充思考` 并报 `400`，将其关闭即可；
  - 若搭配原生思考模型且上下文较长，感觉首字偏慢或双重思考冗长，可关闭 `[思考工具] 输出思考面板` 或将 `[主思考]` 切至 `叙事推理-轻量`；
  - 部分接口不支持惩罚参数时，可在 **参数设置** 点击 **清零惩罚项**；若 Claude 报 `temperature` 与 `top_p` 互斥，请在酒馆 API 连接的「排除请求体参数」中填入 `top_p`；
  - 内置思考会占用回复额度，建议将最大回复长度保持在 `16384`–`32768`。

## 二、预设机制说明（按需查阅）

以下内容面向希望深入了解预设内部结构、精细调优或二次扩展的用户，日常使用可按需查阅。

### 1. 多 AI 人设与四节点交替确认机制
- **三位内置人设**：**`莉莉丝：肉文写手`**（默认开启，魅魔写手，擅长情绪拉扯与成人向互动）、**`泠音：剧情小说`**（温和沉静，注重人物可信度与细节）、**`Ark：角色扮演`**（冷静理性，注重世界自洽与细节观察）。
- **四节点交替确认 + 尾部防接口拒收设计**：激活人设后会在核心规则、故事设定、历史会话与执行规则四个节点分别以搭档口吻确认，并通过顶层 `persona_name` 变量在关键交接点自然呼唤当前搭档；执行确认后紧跟极简 `user` 消息 `继续`，既在生成前拉回人设与完结自强化，又确保常规请求恒以 `user` 结尾（兼容 Gemini 4 / Claude 等禁 `Assistant` 结尾的接口）。
- **纯净接管与自定义扩展**：在悬浮面板点击当前激活的人设即可关闭全部人设，自动回退为中性 `Assistant` 确认并完全交由角色卡演绎；若自建 `[AI人设]` 条目，在末尾附加 `persona_name` 变量即可同步全篇称呼。正文叙事始终与人设腔调隔离，严守故事自身背景与口吻。

### 2. 分层提示词体系与动态分组机制
- **动态分组与 `&` 联动**：面板自动识别 `[分组] 条目名 [单选/多选]` 与 `[分组] 条目名 [单选/多选]&目标1&目标2` 命名格式；带 `&` 绑定的子项仅当任一目标启用时显示，目标全部关闭时自动隐藏并停用。
- **三大功能层分工**：
  - **基础与输出目标层**：`AI人设`、`核心规则`（确立面向成人的虚构互动文学创作边界、三类输入效力、角色自主性与认知隔离）、`视角`、`文风`（经典日轻、新式轻文学、细腻工笔、情色文学、直白肉文、爽利网文、写实白描、古风雅韵、严肃正剧共 9 款，默认 `情色文学`）、`节奏`、`侧重`（均衡全面、对话交锋、动作神态、外貌神韵、心理刻画、环境烘托共 6 款）、`篇幅`、`写作规范`（标准 / 宽松）与 `NSFW倾向`（中性双向 / 男性向 / 女性向，默认 `中性双向`）/`NSFW细化`（反应多样性）；
  - **执行与思考体系层**：`输入处理`（`直接承接 / 演绎展开`，默认 `直接承接`）、`代写边界`（`禁止代写 / 有限延伸 / 自由代写`，默认 `有限延伸`）、`主思考`（叙事推理-重度 / 叙事推理-轻量，单选互斥，默认 `叙事推理-重度`）、`思考增强`（多角色调度、心理潜台词、伏笔与暗线、防谄媚读心、防复读套话，均默认关闭按需开启）与 `思考工具`（输出思考面板、正文批注、预填充思考）；
  - **附加输出与总结层**：`附加输出`（场景状态栏、剧情选项、外部格式兼容）与 `总结`（场景小结 / 全局梳理，单选互斥且全局梳理位于尾部独立任务块，生成后自动关闭）。

### 3. 对话美化与上下文整理机制（12 条内置正则）
- **美化设置（7 条，仅作用于显示层）**：将 `<draft>` 思考过程、`<scene>` 场景状态栏（时间｜地点｜在场人物）、`※ 标签：内容` 正文批注（支持快捷/自定义标签添加与全楼层编辑删除）、`<summary>` 场景小结、`<recap>` 全局梳理档案以及 `<options>` 文末剧情选项（支持角色动向与时间推进、转场、临时切视角等叙事功能项，点击填入保留原有草稿换行追加）渲染为独立界面卡片，并对正文对白（`“...”` / `「...」` / `『...』` 及行内斜体/加粗）与分割线进行润色；各正则均具备闭合与流式未闭合 `<draft>` 隔离保护。
- **其他设置（5 条，均默认开启）**：
  - **`隐藏完结标记`（显示层）**：自动隐藏回复最末尾的 `<ToBeContinue>` 完结标记（排错时可一键关闭核验模型输出完整性，同时保护 `<draft>` 内与正文行内提及不被误删）。
  - **`历史标签过滤`（发送前）**：发给模型前实时剔除历史旧回复中的 `<draft>`、`<options>` 与 `<ToBeContinue>`，不改聊天存档。
  - **`历史状态栏清理` / `历史梳理清理`（发送前按深度）**：自动清理 6 层以前的 `<scene>` 与 30 层以前的 `<recap>`，避免长对话旧定格画面互相干扰；`※` 批注、伏笔与 `<summary>` 随历史持久留存。
  - **`历史禁词清洗`（发送前）**：默认开启低误伤套话修饰词表，仅在发给模型前从 AI 历史回复中剔除，不改聊天记录与界面显示，可在悬浮面板自由增删词条。
